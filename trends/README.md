## レポートの見方
- **🔥 今日のハイライト**：忙しいときはここの3行だけ読めばOK
- **🔥の数**：Claudeが判断した注目度（🔥🔥🔥 = 大ニュース・動画ネタとして強い）
- **🇺🇸 / 🇯🇵 / 🌏**：情報の発信元（アメリカ／日本／その他の国）。アメリカ発を多め（全体で約6:4）に集めています
- **🇯🇵 日本での状況**：アメリカの記事に付く「日本に来ているか」のメモ
- **🇺🇸→🇯🇵 次に日本に来そうなもの**：アメリカで流行り始めて、日本ではまだ知られていないもの
- **[A1] などの記号**：評価用のID（A=AI、V=VR、G=ゲーム、E=経済、T=流行）
- **🆕**：まだ評価したことのない種類の話題（好みの幅を広げるため毎回1件入ります）
- **🔗**：元の記事へのリンク
- **🎬 動画ネタのヒント**：その日の話題から考えた企画案

## ⭐ 評価のしかた（★1〜5）

評価すると、次の日からレポートがあなた好みに変わります。

| 評価 | 意味 | 次回からの扱い |
|---|---|---|
| ★5 | とても興味がある | 似た話題を重点的に・さらに詳しく |
| ★4 | 興味がある | 詳しく |
| ★3 | ふつう | 標準 |
| ★2 | あまり興味がない | 見出しと1〜2文だけ |
| ★1 | 興味がない | 基本的に載せない |

**方法A：Claude に伝える（いちばん簡単）**
このリポジトリのセッションで、たとえば次のように送るだけです。
> 9/26 の評価：A1は5、V1は5、E1は2、T3は1。V1はもっと詳しく知りたい

**方法B：GitHub で直接書く**
1. `trends/ratings/` の日付のファイルを開く
2. 右上の ✏️（鉛筆）ボタンを押す
3. 「評価」の列に 1〜5 の数字を書く（空欄のままでもOK）
4. 下の「Commit changes」を押して保存

**方法C：好みを文章で伝える**
[preferences.md](preferences.md) の「✍️ 手書きメモ」に「VRChatの話題は毎回ほしい」などと書くと、評価よりも優先されます。
